# Aeon bank Assessment project

### how to run

open folder frontend

install the library

`bun install`

do pod install

`cd ios && pod install`

run the project

`bun run ios`

---

### technology

frontend :

- react native
- typescipt
- zustand
- reanimated

backend :

- bun
- elysia js
